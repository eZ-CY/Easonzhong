PROJECT 01 / XH-202614

ShadowTrace

基于可验证证据链图谱推演与动态任务编排的安全运营多智能体系统

揭榜挂帅项目AI + 安全大模型平台的智能体研究Mock XDR 演示闭环

项目概述

ShadowTrace 面向安全运营中心的告警研判与处置，将接入、分诊、取证、知识增强、关系图谱、风险评分、处置计划、分级审批、执行与验证串成可恢复、可审计的流程。

系统强调“先证据、后结论”和“先审批、后副作用”：模型负责受约束的分析与规划，关键动作由后端权限、审批、幂等和独立验证共同控制。

核心流程接入 → 研判 → 审批 → 执行 → 验证
运行方式Mock XDR + Agent / 审批 / 执行闭环
我的关注Agent 编排、RAG、可靠写回

主要实现

01

多智能体编排

基于 LangGraph 状态图组织分诊、取证、风险评分、处置、验证及报告流程；结合 Redis Checkpoint 与 Celery 支持审批挂起、断点恢复和异步任务执行。

02

RAG 与证据链

结合 PostgreSQL / pgvector 向量检索、全文检索与 RRF 融合，检索 ATT&CK、SOAR 剧本及历史案例；关联实体、证据和攻击路径，为研判结论提供可追溯依据。

03

受控处置

通过分级审批、Outbox、幂等控制与外部状态回读组织执行和写回，独立验证动作结果，避免把本地成功状态误认为外部动作已生效。

PROJECT 02 / DELOITTE INTERNSHIP

Delta AI

威胁情报采集与分析工作平台

德勤实习项目可追溯情报分析LLM + 规则评分

项目概述

Delta AI 将威胁情报从来源采集、内容清洗、精确去重推进到结构化分析、确定性评分、人工审核和 Word 周报生成，重点解决来源不可追溯、模型结果难复核和任务执行不稳定的问题。

平台保留原始证据、分析版本、评分版本和审核快照，使每条输出都能回到来源、版本和人工决定。

核心流程采集 → 清洗 → 分析 → 审核 → 报告
数据链路RSS / Atom → Worker → PostgreSQL / Object Storage
我的关注Agent 分析、Schema 校验、结果追溯

主要实现

01

采集与标准化

支持 RSS / Atom 采集、文章获取、HTML 清洗、标题与 URL 标准化、内容指纹和精确去重；保留来源关联和原始对象引用。

02

结构化 AI 分析

通过 OpenAI-compatible Provider 生成技术摘要、管理层摘要、分类、实体、建议动作和证据引用，并使用 Schema 校验和证据引用约束输出。

03

评分与审核报告

使用版本化规则进行质量、风险和置信度评分；人工编辑与批准保留历史版本，最终从批准快照生成不可变 Word 周报。
